# 《IslandMapPrototype》开场 CG 制作与接入规范

## 1. 定位

这段 CG 用 24 秒依次展示汽车、快艇和飞机，快速建立游戏“海陆空载具追逐”的核心识别。成片采用 `16:9`、`24 fps`，按 `7 秒陆地 + 7 秒海面 + 7 秒天空 + 3 秒坠落复位` 制作。

开场流程只播放一遍，结束后进入主界面，不自动循环。首尾同帧和环境底噪闭环仍需保留，用于生成检查及后续菜单动态背景复用。

## 2. 分段结构

| 时间 | 画面 | 转场 | 主要声音 |
| --- | --- | --- | --- |
| `0–7s` | 雨后公路、跑车掠过并进入车后追随 | 轮胎水雾覆盖镜头 | 雨后微风、树叶、远海、湿路轮胎、浅水、汽车发动机 |
| `7–14s` | 水雾转尾流，快艇高速越浪 | 浪花形成中性白遮罩 | 海风、船体拍浪、尾流、单台船外机 |
| `14–21s` | 浪花转云雾，战机进入云层 | 厚云吞没机体 | 高空风、云雾气流、双发动机 |
| `21–24s` | 镜头穿云下坠并回到公路首帧 | 画面与环境底噪首尾对齐 | 下坠气流、轻微触地与砂石、雨后环境底噪 |

## 3. 声音硬约束

全片只允许画面内可解释的自然环境声和载具运行声。声音视角位于第三人称跟拍镜头，不使用驾驶舱内收音。

允许的声音：

- 风、树叶、远处海浪和雨后环境底噪。
- 轮胎压过湿路与浅水、汽车发动机。
- 船体拍浪、尾流、水雾和唯一一台船外机。
- 高空风、穿云气流和飞机双发动机。
- 触地时一次短促闷响、两次极轻回弹和少量砂石声。

禁止的声音：

- 任何背景音乐、旋律、和弦、鼓点、节拍、持续音床或音乐化氛围。
- 人声、对白、旁白、广播、无线电、呼吸、欢呼及可辨识的人类活动声。
- UI 音、标志音、预告片低频冲击、上升音、重低音、转场呼啸和人为强化的电影音效。
- 音爆、武器、爆炸、坠毁、耳鸣、碎裂以及与画面不符的额外发动机声。
- 段落边界突然静音、突然增益、声像跳变或混响空间突变。

## 4. 声音连续规则

1. `7s`：轮胎水雾与快艇尾流交叉衔接 `0.4–0.6 秒`；汽车发动机自然远去后，船外机成为主体。
2. `14s`：拍浪和船外机随白色浪花遮罩远去，高空风从水雾中自然进入，不使用上升音或冲击音。
3. `21s`：飞机进入云层后，发动机随距离快速衰减，只留下穿云与下坠气流。
4. `23.5–24s`：风、远海和雨后底噪逐渐对齐片头 `0–1.2s` 的声场与响度，循环监听时不得出现可闻断点。

## 5. 合理性与风险

海陆空依次亮相与现有三类玩法一致，水雾、浪花和云雾组成的物理遮罩也适合跨场景生成。统一的右侧夕阳、黄昏色温和第三人称镜头能维持视觉连续性。

太阳必须固定在世界空间，不能固定在屏幕右侧。陆地段开头太阳位于画面右侧；汽车掠过后摄像机约反向 `160–180°` 进入车后跟随，此时太阳应位于镜头左后方并完全退出画面。跟拍道路从右下方进入，主要占据画面右半区域，汽车位于中右位置。L05 水雾完全遮满画面前，太阳不得重新出现；只有在不透明水雾遮罩内，才允许重置海面段航向并在 S01 恢复右侧夕阳。

陆地段在 7 秒内同时包含静止、来车、近景掠过、约 180 度绕行和车后追随，是生成风险最高的一段。低成本预览必须先验证运镜和车体一致性；若模型产生跳切或变形，应拆成“掠过镜头”和“车后追随”两个镜头，再利用车身近景或水雾拼接。

坠落复位适合作为循环闭环，但不应在正常启动流程中反复播放。24 秒首次观看可接受，游戏接入时必须提供跳过操作，且跳过不附加冲击音或提示音。

## 6. 游戏接入验收

- 启动开场播放期间，跨场景背景音乐保持停止或静音。
- 视频自然结束或玩家跳过后进入主界面，再淡入主界面背景音乐。
- 开场环境音与主界面背景音乐不得重叠播放。
- 完整播放、跳过、重复启动和无音轨视频四种路径均能正常进入主界面。
- 成片至少连续播放 10 个循环，逐一检查 `7s`、`14s`、`21s` 和 `24s→0s` 的画面与声音接缝。
- 关闭画面单独监听整条音轨，确认不存在音乐、人声、广播或无法由画面解释的声音。
