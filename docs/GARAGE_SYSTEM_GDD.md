# 车库系统设计文档

## 范围

- 开始界面新增“车库”入口。
- 提供三辆陆地车辆：现有默认车、`garage_car_02`、`garage_car_03`。
- 三辆车全部默认解锁，仅改变视觉外观；驾驶参数、碰撞体、生命和技能完全共用现有玩家根节点。
- 装备结果保存到 `Garage.SelectedVehicleId`，故事第一关与陆地无尽模式共用；海上快艇不受影响。

## 车库交互

- 进入车库时冻结游戏时间和音频，退出时恢复进入前状态。
- 预览与装备分离：左右按钮、`A/D` 或方向键循环浏览；`Enter/Space` 装备；`Esc` 返回开始界面。
- 预览车以每秒 20 度自动旋转；鼠标水平拖拽以每像素 0.35 度旋转，最后一次操作一秒后恢复自动旋转。
- 当前装备车辆显示“当前使用”，未装备车辆显示“正在预览”。

## 资源与容错

- 新模型以 OBJ 和 PBR 贴图放在 `Assets/Resources/Vehicles/`，由 Unity 导入为可加载模型资源。
- 新车在运行时使用标准材质、基础色、金属度和法线贴图；材质异常时仍展示模型。
- 存档车型 ID 不存在或模型无法加载时，回退并立即重写为 `default_car`。
- 视觉替换使用独立子树；找不到默认视觉时不替换，保证游戏可继续运行。

## 验收

- 车库可反复进出 20 次，不残留预览相机、灯光、RenderTexture 或车辆预览对象。
- 更换车辆后，玩家根节点的 Rigidbody、Collider 和 `SimpleAutoDriveController` 配置保持不变。
- 两种陆地玩法均在开始前展示已装备车型；海上场景不加载或替换任何车库车型。
