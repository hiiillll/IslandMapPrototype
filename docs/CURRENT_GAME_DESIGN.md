## 2. 游戏概述

《IslandMapPrototype》是一款以自动前进载具为核心的俯视角街机追逐游戏。玩家分别驾驶汽车、快艇和飞机，在陆地、海洋与空中躲避持续出现的追兵，通过转向、漂移、技能、地形利用和敌人连锁碰撞完成生存与撤离目标。

游戏采用章节式剧情流程与独立无尽挑战并行的结构。剧情模式强调场景转换、任务目标和通关 CG；无尽模式强调生存时间、击毁数量、难度增长和历史纪录。

## 3. 核心体验

### 3.1 高速追逐

载具自动保持前进，玩家不需要控制油门，注意力集中在路线判断、转向、躲避和反制追兵上。敌人持续从场外或固定位置进入，通过数量和速度压力压缩玩家的安全空间。

### 3.2 借力击毁

敌方载具碰撞玩家、障碍物或其他敌人后会爆炸。爆炸能够造成范围影响并触发连锁爆炸，玩家可通过急转、漂移、走位和主动技能制造追兵相撞的机会。

### 3.3 局内成长

陆地玩法中，击毁敌车会掉落经验齿轮，并有概率掉落生命包。玩家升级后可强化已装备技能、提高最大生命，或提高生命包掉落概率，使一局内的生存能力逐步增强。

### 3.4 多载具节奏变化

- 汽车强调道路、建筑、漂移和追兵包围。
- 快艇强调大范围水域转向、边界控制和持续追击。
- 飞机增加高度控制，形成平面转向与升降结合的立体躲避。

## 4. 核心循环

### 4.1 剧情模式

1. 从主界面进入剧情模式并选择章节。
2. 在开始第一章时，从五项技能中选择两项，分别装备到 `Q` 和 `E`。
3. 驾驶载具自动前进，通过转向、漂移或升降规避敌人。
4. 利用碰撞、技能和地形击毁敌人，维持生命并完成当前关卡目标。
5. 达成生存时间或收集条件后，前往指定撤离点。
6. 播放关卡 CG，并进入下一关或返回章节选择。

### 4.2 无尽模式

1. 从主界面选择无尽模式。
2. 选择陆地追逐、海上逃生或空中追击。
3. 在不断增强的敌人压力下尽可能长时间生存。
4. 生命归零后结算生存时间与击毁数。
5. 更新对应模式的本地最佳纪录，并选择重新挑战或返回模式选择。

## 5. 游戏流程

### 5.0 启动开场 CG（待最终视频素材接入）

游戏启动后、进入主界面前播放一段 24 秒的海陆空开场 CG，依次展示汽车、快艇和飞机，并以雨后热带火山岛公路画面收束。开场默认只播放一遍，不在启动流程中自动循环；玩家可跳过并直接进入主界面。

开场 CG 只使用画面内可解释的自然环境声与载具运行声，包括风、树叶、远处海浪、湿路轮胎与浅水、汽车发动机、船体拍浪、单台船外机、飞机发动机、云层气流和轻微砂石声。禁止背景音乐、人声、对白、旁白、广播、UI 音、预告片式冲击音和音乐化转场声。

CG 播放期间暂停跨场景背景音乐，由视频环境音轨独占输出。视频自然结束或玩家跳过后进入主界面，再按主界面原有规则淡入背景音乐，禁止两条音轨重叠。

### 5.1 主界面

主界面提供三个入口：

- 剧情模式
- 无尽模式
- 车库

剧情模式可选择第一章或第二章。第二章需要完成第一章后解锁；已有剧情进度时可继续当前章节。

### 5.2 剧情结构

```text
第一章第一关：岛屿追逐
        ↓ 生存完成，前往码头
      过场 CG
        ↓
第一章第二关：海上逃生
        ↓ 生存完成，前往撤离飞机
      通关 CG
        ↓ 解锁第二章
第二章第一关：宝箱撤离
        ↓ 收集 4 个宝箱，前往飞机场
      通关 CG
        ↓ 直接进入下一关
第二章第二关：空中追击
        ↓ 生存完成
   第二章完成并返回菜单
```

## 6. 剧情关卡设计

### 6.1 第一章第一关：岛屿追逐

| 项目 | 设计内容 |
| --- | --- |
| 场景 | 热带岛屿城市、道路、建筑、草地、沙滩与码头 |
| 玩家载具 | 汽车 |
| 基础目标速度 | 25.3 m/s，约 91 km/h |
| 关卡目标 | 生存 120 秒，随后前往码头撤离 |
| 敌人 | 地面追击车辆 |
| 通关方式 | 抵达码头区域后按 `F` 互动 |
| 转场 | 播放码头离开 CG，进入第一章第二关 |

关卡开始后，敌车从岛上的生成点持续出现并通过导航路线追击玩家。故事难度从预热阶段起步，在 120 秒内逐步提高，主要变化包括：

- 敌车生成间隔逐步缩短。
- 场上敌车数量上限逐步提高。
- 敌车速度由低于玩家逐步提升至略高于玩家。

计时结束后停止生成并清理敌人，界面提示玩家前往码头。玩家进入码头范围并按 `F` 后播放 CG。

### 6.2 第一章第二关：海上逃生

| 项目 | 设计内容 |
| --- | --- |
| 场景 | 4000 × 4000 的开放海域 |
| 玩家载具 | 快艇 |
| 初始速度 | 30 m/s，约 108 km/h |
| 最高阶段速度 | 36 m/s，约 129.6 km/h |
| 关卡目标 | 生存 120 秒，随后前往撤离飞机 |
| 敌人 | 敌方快艇 |
| 通关方式 | 进入飞机撤离范围后按 `F` 互动 |
| 转场 | 播放海上撤离 CG，解锁并进入第二章 |

玩家速度在前 50 秒内线性提升，敌艇目标速度始终比玩家高 `2.1 m/s`。敌艇在镜头外生成，生成间隔由 `2.5` 秒逐步缩短至 `0.55` 秒，场上最多存在 12 艘敌艇。

计时结束后，撤离飞机生成在玩家附近，并通过方向指引提示位置。玩家抵达飞机后完成撤离。

### 6.3 第二章第一关：宝箱撤离

| 项目 | 设计内容 |
| --- | --- |
| 场景 | 大型岛屿城市、住宅区、商业建筑、警察局、道路与飞机场 |
| 玩家载具 | 汽车 |
| 玩家目标速度 | 28 m/s，约 100.8 km/h |
| 敌人目标速度 | 29 m/s，约 104.4 km/h |
| 关卡目标 | 从 5 个宝箱中收集任意 4 个，然后前往飞机场 |
| 敌人 | 警车 |
| 通关方式 | 收集完成后抵达飞机并按 `F` 互动 |
| 转场 | 播放通关 CG，结束后直接进入第二章第二关 |

宝箱上方设置贯通天空的半透明引导光柱，帮助玩家在大地图中识别目标。车辆进入宝箱触发范围后自动收集，宝箱播放开盖动画并在短暂停留后隐藏。

HUD 持续显示宝箱收集进度：

- 未完成时显示“宝箱进度”和当前数量。
- 提示玩家寻找光柱下的宝箱。
- 达到 `4/4` 后切换为“前往飞机场”。
- 同时提示撤离点已经解锁。

警车速度全程保持 `29 m/s`。生成压力在 120 秒内持续提高，生成间隔由 `4.3` 秒逐步缩短至 `1.2` 秒，场上数量上限由 6 辆提高至 16 辆。

玩家抵达飞机并按 `F` 后播放 CG。CG 播放完成后立即进入第二章第二关，不显示额外的关卡完成界面。

### 6.4 第二章第二关：空中追击

| 项目 | 设计内容 |
| --- | --- |
| 场景 | 云层与开放空域 |
| 玩家载具 | 飞机 |
| 初始速度 | 36 m/s，约 129.6 km/h |
| 最高阶段速度 | 42 m/s，约 151.2 km/h |
| 关卡目标 | 生存 120 秒 |
| 敌人 | 敌方追击飞机 |
| 通关方式 | 生存计时结束 |
| 转场 | 显示第二章完成信息并返回菜单 |

玩家可进行水平转向和高度调整，飞行高度限制在 `8` 至 `56` 之间。玩家速度在前 50 秒内线性提升，敌机始终比玩家快 `1.5 m/s`。

敌机在镜头外生成，生成间隔由 `2.5` 秒逐步缩短至 `0.55` 秒，场上最多存在 12 架敌机。完成 120 秒生存后清理敌人，显示“空中追击完成”和“第二章已通关”，随后返回菜单。

## 7. 操作设计

| 输入 | 汽车 | 快艇 | 飞机 |
| --- | --- | --- | --- |
| `A/D` 或左右方向键 | 左右转向 | 左右转向 | 左右转向 |
| `W/S` 或上下方向键 | 无 | 无 | 上升/下降 |
| `Space` | 漂移 | 无 | 无 |
| `Q` | 使用第一项技能 | 无 | 无 |
| `E` | 使用第二项技能 | 无 | 无 |
| `F` | 码头、飞机撤离互动 | 飞机撤离互动 | 无 |
| HUD 暂停按钮 | 暂停游戏 | 暂停游戏 | 暂停游戏 |

所有载具均自动向前移动。汽车漂移需要车辆达到目标速度的 30% 以上，同时按住 `Space` 并输入转向。

## 8. 战斗与生存规则

### 8.1 生命

- 玩家基础最大生命为 3 点。
- 与敌方载具碰撞时受到 1 点伤害。
- 受伤后获得 1 秒伤害保护。
- 生命归零后停止玩家载具并进入失败或结算流程。
- 陆地玩法中跌落到世界高度 `Y < -10` 时直接失败。

### 8.2 敌人碰撞

- 敌人与玩家碰撞后爆炸。
- 敌人与其他敌人碰撞可触发双方爆炸。
- 地面敌车撞击静态障碍物后爆炸。
- 爆炸可影响附近敌人，形成连锁爆炸。

### 8.3 掉落物

| 掉落物 | 效果 | 存在时间 |
| --- | --- | --- |
| 经验齿轮 | 增加 20 点经验 | 25 秒 |
| 生命包 | 恢复 1 点生命 | 25 秒 |

地面敌车基础生命包掉落概率为 10%，该概率可通过升级奖励提高。经验齿轮具有 3 米自动拾取范围。

## 9. 技能系统

开始第一章第一关或陆地无尽模式前，玩家从五项技能中选择两项，依次装备到 `Q` 和 `E`。同一项技能不能同时占用两个槽位。第二关海上逃生不加载技能系统，也不显示技能与经验 HUD。

| 技能 | 基础效果 | 初始冷却 | 强化后冷却 |
| --- | --- | ---: | ---: |
| 小喇叭 | 释放范围冲击，击退并破坏附近敌车 | 4.5 秒 | 3 秒 |
| 重力陷阱 | 在车辆后方布置牵引敌人的范围陷阱 | 11 秒 | 8 秒 |
| 空间移动 | 沿车辆前方瞬间位移并维持最低出场速度 | 7 秒 | 5 秒 |
| 烈焰尾迹 | 在车辆后方留下可破坏敌人的火焰区域 | 12 秒 | 9 秒 |
| 汽车？坦克！ | 向车辆后方发射爆炸炮弹 | 10 秒 | 7 秒 |

技能强化不仅缩短冷却，还会提高对应技能的范围、持续时间、力度、位移距离或爆炸能力。技能释放配有独立音效和视觉反馈。

## 10. 等级成长

### 10.1 经验需求

- 初次升级需要 80 点经验。
- 此后每一级的需求增加 20 点。
- 经验需求依次为 80、100、120、140……
- 超出当前等级需求的经验会保留到下一级。

### 10.2 升级奖励

| 到达等级 | 奖励规则 |
| --- | --- |
| 2 级 | 强化一项已装备且未强化的技能 |
| 3 级 | 强化另一项已装备且未强化的技能 |
| 4 级 | 在“最大生命 +1”和“生命包掉落概率 +10%”之间选择 |
| 5 级及以上 | 每级最大生命 +1，并恢复 1 点生命 |

升级选择期间暂停游戏时间，完成选择后恢复游戏。

## 11. 无尽模式

### 11.1 通用规则

- 无固定通关时间，持续到玩家生命归零。
- 难度在前 180 秒内平滑提高，之后保持最高强度。
- 在 60 秒、120 秒和 180 秒显示阶段提示。
- 结算生存时间和击毁数量。
- 每种无尽模式分别保存最长生存时间与最高击毁纪录。
- 结算界面提供重新挑战和返回模式选择。

### 11.2 陆地追逐

- 使用第一章第一关岛屿地图和汽车驾驶规则。
- 保留技能选择、经验、升级和生命成长。
- 敌车生成间隔由 `4.3` 秒缩短至 `1.2` 秒。
- 敌车上限由 6 辆提高至 16 辆。
- 敌车速度比例由玩家速度的 90% 提高至 105%。

### 11.3 海上逃生

- 使用第一章第二关海域和快艇驾驶规则。
- 玩家速度固定为 `30 m/s`。
- 不提供技能、经验和升级。
- 敌艇速度优势由 `0.5 m/s` 提高至 `2 m/s`。
- 生成间隔由 `2.5` 秒缩短至 `0.65` 秒。
- 敌艇上限由 12 艘提高至 24 艘。
- 接近海域边界时显示警告和返回中心方向。

### 11.4 空中追击

- 使用第二章第二关空域、飞机驾驶和敌机规则。
- 不提供技能选择和局内成长。
- 以生存时间和击落敌机数量作为结算指标。

## 12. 车库系统

车库用于选择陆地玩法中的玩家汽车外观。所有车辆默认解锁，仅改变外观，不改变速度、转向、碰撞体、生命和技能数值。

当前车辆共 5 辆：

1. 经典座驾
2. Porsche 911 GT3 RS
3. BMW M4
4. Nissan GTR
5. Ferrari F40

车库支持以下操作：

- 使用 `A/D`、左右方向键或界面按钮切换车辆。
- 使用 `Enter` 或 `Space` 装备当前车辆。
- 使用鼠标拖动旋转预览车辆。
- 无操作时车辆自动旋转展示。
- 当前装备车辆通过本地存档保留。

车库车辆应用于陆地剧情和陆地无尽玩法，不改变快艇与飞机外观。

## 14. 美术与镜头方向

游戏采用 3D 俯视追逐视角，以较大的可视范围保证高速状态下的路线判断。镜头跟随载具移动，并在受伤、碰撞或重要难度节点提供震屏反馈。

陆地场景以明亮热带城市为基础，结合较写实的自然光、环境雾、阴影和 PBR 材质，整体质感靠近开放世界车辆游戏，同时保留街机游戏所需的高辨识度。第三关的宝箱光柱使用半透明高亮效果，在远距离承担导航功能。

海上场景强调开阔水域、快艇航迹和追击包围；空中场景强调云层、高速气流、机体倾斜与高度变化。

UI 使用高对比度的街机仪表风格，重要目标、技能状态、生命和收集进度在高速移动中保持可读。

## 15. 音频与过场

- 游戏使用跨场景持续播放的背景音乐。
- 启动开场 CG 是背景音乐规则的例外：播放期间不输出任何背景音乐，只播放视频内的自然环境声与载具运行声。
- 启动开场 CG 禁止人声、旁白、广播、音乐化氛围、预告片式冲击音和人为转场音；结束或跳过后才淡入主界面背景音乐。
- 五项主动技能具有独立音效。
- 敌人爆炸、拾取、受伤和难度里程碑提供对应反馈。
- 第一章第一关、第一章第二关和第二章第一关通过全屏视频 CG 完成场景转场。
- 播放 CG 时暂停常规游戏时间，并由视频音轨接管过场声音。
